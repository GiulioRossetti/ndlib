*******************
Node Compartments
*******************

Node compartments evaluate conditions tied to node status, node attributes, or
node-local numeric variables. They are the basic predicates used to build
transition rules in the classic custom-model API.

Use this page when you need to understand the primitives that inspect the
current node being updated.
